# Handoff B3: testing kit (`gonesttest`)

## Files
`builder.go` (Builder, App, Get/GetNamed), `shadow.go` (module graph copy), `request.go`, `response.go`, `ctx.go` (NewCtx, Recorder, ResponseOf), `doc.go`; tests: `gonesttest_test.go` (3-module integration with overrides), `internal_test.go` (failure paths via a fake TB), `example_test.go` (runnable Examples), `fixtures_test.go`.

## Public API
- `New(t, root) *Builder`; `OverrideProvider(Provider)`, `OverrideModule(old, new)`, `WithOptions(...gonest.Option)`, `Compile() *App`.
- `App` embeds `*gonest.App`; `Get[T](app)`, `GetNamed[T](app, name)` (fail the test on error; root visibility as `gonest.Get`).
- `app.Request(method, path)`: `WithHeader`, `WithQuery`, `WithBearer`, `WithJSON`, `WithBody`, `Do()`.
- `Response`: `Status`, `Body`, `Header`, `JSON(v)`, `ExpectStatus`, `ExpectJSON`, `ExpectHeader`, `ExpectErrorMessage` (the Expect methods return the Response for chaining).
- `NewCtx(t, ...CtxOption)`: `CtxMethod`, `CtxPath`, `CtxHeader`, `CtxQuery`, `CtxParam`, `CtxBody`, `CtxJSON`, `CtxRoute`, `CtxMetadata`, `CtxLogger`, `CtxSet`. `Recorder(ctx)`, `ResponseOf(t, ctx)`.

## Decisions
- Overrides use a shadow copy of the reachable graph (identity preserved: a module imported twice is copied once; cycles tolerated, B1 reports them). Caller modules are never mutated (tested). Controllers, Configure and unrelated providers are shared.
- Providers are matched by Token. A replacement without an enhancer kind inherits the replaced provider's (so `Provide(newGuard)` stays a global guard). To swap a guard for a differently typed one, use `OverrideModule` or `WithOptions(WithGlobalGuards(...))`.
- Strictness: an override matching nothing (provider token or module) fails `Compile` (catches typos); NestJS silently ignores it.
- `Compile` defaults: `WithoutStartupLog`, discard logger; `WithOptions` come after and win. Cleanup runs `Shutdown` (30s) via `t.Cleanup`.
- `ExpectJSON` normalises both sides through encoding/json (numbers compare by value, structs ok). `ExpectErrorMessage` also searches `details`, so validation field names work.
- `NewCtx.Route()` is never nil (method, path, metadata). `Recorder` stores the recorder under a gin key, flushes an unwritten non-200 status, and returns nil for foreign Ctx values.
- Imports `internal/core` only for `core.NewCtx`.

## Coverage
97.8% (`go test -race -cover ./gonesttest/`); gofmt, vet, golangci-lint clean.

## Known gaps
- No request-scoped providers (not in v0.1); no way to override a provider only for one module; no cookies/multipart helpers on `Request` (use `WithBody`); `Request.Do` uses httptest, not a real listener.
