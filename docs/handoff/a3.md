# Handoff A3: modules/config and modules/logger

Both packages import only `github.com/omyo-group/gonest`, gin, validator and the standard library. Exception: `modules/logger/logger_test.go` imports `internal/core` for `core.NewCtx`, because the public package has no way to build a `*Ctx` for testing `FromCtx`.

## modules/config
Exported API:
- `Options{Prefix, EnvFiles, RequireEnvFiles, Lookup, NotGlobal}`
- `ForRoot[T](Options) *gonest.Module`: module "config", global unless `NotGlobal`, provides and exports `*T`.
- `ForFeature[T](Options) *gonest.Module`: non-global, named `config:<type>`, exports `*T`.
- `Load[T](Options) (*T, error)`
- `Redacted(v any) string`
- `ParseEnv(content string) (map[string]string, error)`: the .env parser, exported for reuse and testing.
- `Error{Problems []string}`: aggregated error returned by `Load`.

Decisions:
- Precedence is default tag, then .env files (later files override earlier ones), then real environment variables. An empty but set variable counts as set.
- `opts.Prefix` applies to every variable, including explicit `env:"X"` tags.
- Nested struct fields use `envPrefix:"DB_"`. Without the tag the prefix is derived from the field name (`Auto` becomes `AUTO_`). Embedded (anonymous) structs add no prefix unless tagged.
- A pointer-to-struct section is always allocated.
- `env:"-"` skips a field.
- Names derive as UPPER_SNAKE with acronym handling (`APIKey` becomes `API_KEY`, `PoolSize` becomes `POOL_SIZE`).
- Conversion errors are reported first. Validation runs only if conversion succeeded, so validation problems are never reported on half-parsed values.
- Problems name the env variable. Values of `secret:"true"` fields are never included in error messages.
- Supported types: string, bool, ints, uints, floats, `time.Duration`, `time.Time` (RFC3339), `url.URL` and `*url.URL`, `encoding.TextUnmarshaler`, pointers to these, and slices of any supported element (comma separated).
- .env parser: `KEY=VALUE`, `export` prefix, `#` comments (including a trailing ` #`), single quotes (literal), double quotes (`\n \t \r \" \\` escapes), BOM, CRLF. No variable expansion and no multi-line values.
- Malformed .env lines are collected into the `Load` error.

Gap: YAML is out of scope (no dependency allowed).

## modules/logger
Exported API:
- `Options{Level, Format, Output, AddSource, Attrs}`
- `New(Options) *slog.Logger`
- `ForRoot(Options) *gonest.Module`: module "logger", global, provides and exports `*slog.Logger`. It does not call `slog.SetDefault`.
- `RequestLogger(*slog.Logger) gin.HandlerFunc`
- `FromCtx(*gonest.Ctx) *slog.Logger`
- Constants `ContextKey` ("gonest.logger"), `RequestIDKey` and `RequestIDHeader` ("X-Request-ID").

Decisions:
- The default format is json when GIN_MODE=release, else text.
- Incoming request ids are accepted only if they are printable ASCII (no spaces) and at most 128 bytes. Otherwise a 128-bit crypto/rand hex id is generated, which prevents log injection.
- The log message is "request". The attributes are method, path, status, latency (a `slog.Duration`, so nanoseconds in JSON), bytes and client_ip.
- `RequestLogger` does not set `Ctx.Logger` itself. `FromCtx` reads the gin key. Once B1 mounts the middleware, `Ctx.SetLogger` can be wired from there if desired.
