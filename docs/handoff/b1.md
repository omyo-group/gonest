## Public API

`Visibility`, `CollectMiddleware`, `Configure`, `Middleware`, `Lifecycle`,

(internal, usable by gonesttest/B3: `Bootstrap` takes a `pipeline.Globals` and
an engine and returns the container, route table, graph and lifecycle).

## Behaviour and decisions
- **Graph**: edges are `Imports` then `ReExports`; a re-exported module is
  implicitly imported. Errors: nil root, nil entries (`Imports[i]`),
  empty Name (names the importer), two `*Module` with the same Name (names
  both importers), cycles `a -> b -> a`.
- **Dependency order**: post-order DFS starting from global modules (in
  discovery order), then the root. Every module follows its imports; global
  modules (e.g. config, logger) are initialised before their implicit users.
- **Visibility**: as in B1.md, plus: a module may export a token it sees
  through imports (re-exporting a provider), through any depth; a global
  module's re-exports (modules and tokens) are global as well. Computed as a
  fixpoint (global modules can make "sees" cyclic). `Visible` is two map
  lookups. Exports validation: zero tokens and tokens neither provided nor
  visible from imports are errors (all reported, joined).
- **Framework providers** (nil owner): `*core.RouteTable` and `*slog.Logger`.
  **Deviation**: the framework logger is *always* registered (from
  `WithLogger`, else `slog.Default()`), as a fallback. The container prefers
  own/visible module providers, so `logger.ForRoot` still wins; without this
  the contract example (private logger in the root) fails. Proposal appended
  to docs/contract-changes.md. The app logger (pipeline + startup log) is the
  logger resolved from the root.
- **Engine**: `WithEngine` or `gin.New()` (no Logger/Recovery). Gin is switched
  to release mode only when creating the engine, `GIN_MODE` is unset and the
  mode is still debug (tests stay in gin's test mode). `InstallFallbacks`
  (JSON 404/405) is always installed, also on a user engine; call
  `app.Engine().NoRoute(...)` after `New` to override.
- **Middleware**: `Configure` must be `func(*MiddlewareConsumer, deps...)`
  optionally returning `error`; deps (plain or `gonest.In` objects) are injected
  from the module through a `reflect.MakeFunc` wrapper passed to
  `Container.Invoke`. RouteSpec paths without a leading `/` are normalised.
  Matching strips `GlobalPrefix` first (NestJS semantics). Handlers are
  returned in module dependency order, then declaration order.
- **Controllers**: invoked from their module in dependency order; the first
  result must implement `Controller`. Controller instances are lifecycle
  targets (after the providers of their module).
- **Globals**: `WithGlobal...` options first, then `Container.Enhancers()` by kind.
- **Hooks**: targets = framework instances, then per module (dependency
  order) its singletons in creation order, then its controllers. Pointer
  values present twice (same Value in two modules) are called once. Each hook
  gets a 30s timeout context; panics become errors. Start: all
  `OnModuleInit`, then all `OnApplicationBootstrap`. On failure the targets
  that completed `OnModuleInit` get the three shutdown hooks in reverse, and
  `New` returns the hook error (naming type and module) joined with cleanup
  errors. Stop: three phases, each over all targets in reverse; every hook
  runs; errors joined.
- **Listen**: `http.Server{ReadHeaderTimeout: 10s, IdleTimeout: 120s}`,
  `signal.NotifyContext(SIGINT, SIGTERM)`, then `Serve`.
- **Serve**: sets a nil `srv.Handler`, uses TLS when `srv.TLSConfig` has
  certificates. On ctx cancel: `srv.Shutdown` bounded by `ShutdownTimeout`
  (default 10s; non-positive values mean default), `srv.Close` if that times
  out, then `App.Shutdown`. If the server fails to start, hooks still run and
  the error is returned. Returns nil after a clean shutdown.
- **Shutdown**: `sync.Once`; later calls return nil.
- **Get/GetNamed**: root visibility only (root's providers, imports' exports,
  re-exports, globals, framework). A provider private to another module gives
  a `*ResolveError` "not visible". A nil interface value returns the zero T.
- **Startup log** (Info): `gonest: modules loaded` (count, names),
  `gonest: mapped route route="GET /users/:id -> UsersController.FindOne"`
  per route, `gonest: application started` (routes, duration).

## Numbers
- Coverage: `internal/module` 99.2%, root package 97.6%.
- `modules/config/integration_test.go` (A3) now runs and passes.
- Nothing of B1 runs per request (middleware matching happens at mount).

## Known gaps
- Resources created by constructors are not released if `New` fails before
  the hooks run (e.g. a mount error): no hook was started, so none is called
  (same as NestJS).
- `Serve` cannot report the bound port for `Addr: ":0"`; tests pick a free port.
- Global modules must be reachable from the root (they are only discovered
  by the walk), as required.
