# Handoff B2: OpenAPI (`openapi`)

## What was built

| File | Content |
|---|---|
| `types.go` | OpenAPI 3.1 model (Document ... Schema, `SchemaType`), `BearerJWT`, `APIKeyHeader` |
| `schema.go` | Go type -> schema (components, $ref, recursion, validate/doc/example/default tags) |
| `generate.go` | `Generate`, `WriteFile`, options, operations/parameters/bodies/responses |
| `module.go` | `Module(Options)`, docs controller (JSON, UI page, assets) |
| `ui.go` + `ui/` | embedded Swagger UI 5.34.0 (`swagger-ui-bundle.js`, `swagger-ui.css`, `LICENSE`), HTML page |
| `*_test.go`, `testdata/sample.json` | golden test (`-update`), structure checks, rule tables, UI/controller tests, integration test |

ADR: `docs/adr/0002-openapi.md`.

## Public API

```go
const Version = "3.1.0"; const DefaultJSONPath = "/openapi.json"; const DefaultUIPath = "/docs"
func Generate(routes []*gonest.RouteInfo, info Info, opts ...Option) (*Document, error)
func WriteFile(doc *Document, path string) error
func Module(opts Options) *gonest.Module
type Options struct { Info; Servers; SecuritySchemes map[string]SecurityScheme; JSONPath, UIPath string; DisableUI bool }
func WithServers(...Server) Option; func WithSecurityScheme(name string, s SecurityScheme) Option
func BearerJWT() SecurityScheme; func APIKeyHeader(name string) SecurityScheme
// model types: Document, Info, Contact, License, Server, Tag, PathItem, Operation, Parameter,
// RequestBody, Response, MediaType, Components, SecurityRequirement, SecurityScheme, SchemaType, Schema
```

## Decisions

- The module's controller is built by a constructor taking `*gonest.RouteTable`; the document is built in
  `OnApplicationBootstrap` and, as a safety net, lazily on first request (`sync.Once`) in case B1 does not
  invoke lifecycle hooks on controllers. A build error (e.g. undefined security scheme) fails bootstrap.
- Routes: JSON at `JSONPath`, page at `UIPath`, assets at `UIPath/*file`; all `Hidden`. `UIPath/` redirects to
  `UIPath`. The page uses relative URLs computed from the two paths, so `WithGlobalPrefix` works.
  Verified with a throwaway gin test that `/docs` and `/docs/*file` coexist.
- Component names: `pkg.Type` (package name, not path), generics as `pkg.Page_other.User`; the JSON-body view of an
  input is `pkg.TypeBody`; `ErrorBody` is fixed.
- Body only for POST/PUT/PATCH. `Security("a","b")` = alternatives (OR). Required = `validate:"required"` and not
  json `omitempty`; nothing else is required. Duration is documented as string. Untagged exported fields of
  Out types follow encoding/json (Go name).
- Tags fall back to the first static path segment, which includes a global prefix (`api`).
- operationId = `Handler.Name`; duplicates get `_<method>` then `_N`.
- Every path parameter is declared (string) even when the input struct does not name it (raw handlers).

## Known gaps

- Global guards (`AppGuard`, `WithGlobalGuards`) are not visible in `RouteInfo`, so routes covered only by them get
  no 401/403 responses and no security requirement.
- Integration test (`TestIntegration`) skips while `gonest.New` returns `core.ErrNotImplemented`; it has not yet run
  against B1's implementation. Please run `go test ./openapi -run Integration -v` after merging B1.
- No oauth2 flows, callbacks, links, discriminators; `time.Duration` JSON is really an integer (spec says string).
- Cookie parameters, multi-value `style/explode`, `any` method (`Router.Handle` with unusual methods) are not
  supported; unsupported methods make `Generate` fail.
