# Handoff C2: integration review

The full report is `docs/review.md`: findings by severity with file:line,
the fixes applied (one commit each on `agent/c2`), benchmarks before and
after, per-package coverage, and the v0.1 recommendation (GO, with known
limitations).

## Decisions
- Request logger convention: `pipeline.LoggerKey` ("gonest.logger", equal to
  `logger.ContextKey`, pinned by a test) is read when the Ctx is built. Core
  and the root package are unchanged.
- The response is encoded before writing (gin's codec), so encoding failures
  become logged 500s.
- OpenAPI durations: integer nanoseconds in JSON, strings in parameters.
- New additive API: `openapi.Options.RouteOptions`.

## Open items for the lead
M4 `WithBodyLimit` (root option) and M5 global security in OpenAPI; m5 to m13
in docs/review.md.
