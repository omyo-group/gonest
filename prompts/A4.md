# Agent A4: CLI

## You own
cmd/gonest/ and internal/codegen/. Use cobra and text/template with templates
embedded via embed.FS. The framework runtime is still being written by others:
generated code must use ONLY the public API documented in docs/contracts.md and
compile against the current root package (stubs are fine for compiling).

## Build
- `gonest new <name> [--module github.com/acme/name] [--dir path]`: project
  with go.mod (requiring github.com/omyo/gonest; flag --gonest-replace PATH adds
  a replace directive for local development), main.go, internal/app/app_module.go,
  config module wiring (`config.ForRoot[AppConfig]`) and logger module wiring,
  a health controller (GET /health), Makefile, Dockerfile (multi-stage, static
  binary, distroless), .golangci.yml, .gitignore, README.
- `gonest generate|g module|controller|service|guard|interceptor|filter|pipe|dto <name>
  [--path internal/users] [--flat] [--dry-run]`: idiomatic code using only the
  root contracts, each with a _test.go. Names: kebab/snake/camel input
  normalised (users, user-profile -> UserProfile, user_profile package).
- When generating controller/service/guard into a directory that holds a
  `*_module.go` with a `&gonest.Module{...}` literal, add the constructor to
  Controllers or Providers using go/ast (go/parser + go/format), never string
  replacement; if the literal cannot be found or edited safely, print the line
  to add instead.
- `gonest info`: Go version, Gonest version (const in internal/codegen), Gin
  version from build info when available.
- Write files atomically; never overwrite an existing file unless --force.

## Acceptance
- Golden-file tests for every template (testdata/*.golden, -update flag).
- End-to-end test: run `gonest new` into t.TempDir() with a replace directive
  to the repo root, generate a module, controller and service, then run
  `go build ./...` (and `go vet`) inside it with the same environment you use
  (GOFLAGS=-mod=mod is needed inside the generated project only; copy the
  repo's go.sum into the generated project first so no network is needed).
  Skip with t.Skip when `go` is not on PATH.
- Coverage >= 80% on internal/codegen. Handoff: docs/handoff/a4.md.
