# Agent B1: module system and application lifecycle

## You own
internal/module/, and in the root package: app.go, lifecycle.go (new) and
their tests. Replace the stubs in app.go keeping every exported signature.
Read docs/handoff/a1.md, a2.md, a3.md first, and docs/contracts.md
"Bootstrap order".

## Build
- Graph: walk Imports and ReExports from the root, dedupe by pointer, detect
  import cycles with the path ("a -> b -> a"), require non-empty unique module
  names (two different *Module with the same Name is an error naming both).
- Visibility (installed with Container.SetVisibility): a provider owned by
  module O with token T is visible from module F when F == O; or O is nil
  (framework); or T is exported by O and (F imports O, or F imports a module
  that re-exports O — transitively through ReExports chains); or O is Global
  and exports T. A module's Exports may only list tokens it provides or that
  it can see from imports (re-exporting a provider); validate at bootstrap
  with a clear error. Global modules must still be reachable from the root.
- Bootstrap in gonest.New, following docs/contracts.md. Framework providers:
  *core.RouteTable, *slog.Logger (only if no module provides one; the logger
  comes from WithLogger or slog.Default()). gin engine: WithEngine or gin.New()
  with gin.Recovery() NOT added (the pipeline recovers); set gin to release
  mode unless GIN_MODE is set, without mutating global state more than gin
  requires.
- Controllers: Invoke each constructor as seen from its module; the result
  must implement core.Controller (error otherwise). Track controller instances
  for lifecycle hooks too.
- Middleware: invoke each module's Configure (if set) via Container.Invoke
  with a *core.MiddlewareConsumer as the first argument — the container cannot
  inject it, so wrap: build a closure that resolves the remaining params, or
  extend through a small helper in your package. Then MiddlewareFor(method,
  path) returns, in module dependency order (imported modules first), the
  handlers of every matching rule.
- Globals: WithGlobal... options first, then Container.Enhancers() mapped by kind.
- Hooks: OnModuleInit and OnApplicationBootstrap for every instance (providers
  from Instances() and controllers), grouped by module in dependency order
  (imports before importers; within a module, creation order). Each hook gets
  a context with a 30s timeout. A failing hook aborts New: already-started
  instances get the shutdown hooks; error names module and type.
- Listen(addr): http.Server with sensible timeouts (ReadHeaderTimeout 10s),
  signal.NotifyContext(SIGINT, SIGTERM), graceful Shutdown with
  ShutdownTimeout (default 10s), then App.Shutdown. Serve(ctx, srv) same with
  a caller-provided server and context. Shutdown(ctx): idempotent (sync.Once),
  runs OnModuleDestroy, BeforeApplicationShutdown, OnApplicationShutdown in
  reverse order, errors.Join all errors.
- Startup log (unless WithoutStartupLog): modules loaded, each route
  "GET /users/:id -> UsersController.FindOne", boot duration.
- Get[T]/GetNamed[T]: resolve as seen from the root module (fall back to
  searching any module that owns the token if not visible from root? NO —
  root visibility only, plus framework providers; document it).

## Acceptance
- Tests: visibility matrix (own, imported+exported, not exported, re-export
  chain, global, framework), import cycles, duplicate names, dedupe,
  Exports validation, hook ordering on start and stop (record a trace),
  failing hook cleanup, middleware Configure with injected deps and
  Exclude/ForRoutes, global enhancers from providers, Listen/Serve graceful
  shutdown (use Serve with a context you cancel), Get/GetNamed.
- Integration test booting a 3-module app over httptest end to end, plus the
  contract example (examples_contract_test.go) actually serving requests.
- Coverage >= 85% on internal/module and the root package.
- Handoff: docs/handoff/b1.md.
