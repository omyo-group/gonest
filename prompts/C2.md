# Agent C2: integration reviewer

## Your role
You did not write this code. Review the merged main branch as a demanding
maintainer preparing v0.1. Fix small issues directly (commit on your branch);
write up anything larger.

## Check
1. Contract fidelity: every root contract implemented; no package reaches into
   another's internals beyond docs/contracts.md seams; no exported API beyond
   what is documented without reason.
2. NestJS parity: pipeline order, filter precedence, module visibility,
   lifecycle order behave as documented. Add tests for any gap you find.
3. Performance: run the benchmarks; confirm no DI lookups, tag parsing or
   chain composition per request (read the code paths, use -benchmem and
   `go test -cpuprofile` + `go tool pprof -top`). Compare with raw Gin.
4. Robustness: `go test -race -count=3 ./...`; fuzz the binder for 2 minutes
   (add a Fuzz test in internal/pipeline if none exists); graceful shutdown
   under concurrent load.
5. API ergonomics: write a fresh small module using only docs/guide; list every
   point where you had to read source code.
6. Consistency: naming, error messages, doc comments, golangci-lint clean,
   coverage per package (`make cover`).

## Output
docs/review.md: findings sorted by severity (blocker, major, minor), each with
file:line, evidence and suggested fix; the fixes you applied; per-package
coverage; benchmark table; a v0.1 go/no-go recommendation.
