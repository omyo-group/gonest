# Agent B2: OpenAPI

## You own
openapi/ only. Use ONLY the public root package (gonest) plus the standard
library: no OpenAPI dependency is allowed (document this choice in
docs/adr/0002-openapi.md — you may create that file).

## Build
- Hand-written OpenAPI 3.1 types (Document, Info, Server, PathItem, Operation,
  Parameter, RequestBody, Response, MediaType, Schema, Components,
  SecurityScheme) with json tags, omitempty everywhere sensible.
- `openapi.Generate(routes []*gonest.RouteInfo, info openapi.Info, opts ...) (*Document, error)`
  pure function (easy to golden-test).
- `openapi.Module(opts openapi.Options) *gonest.Module`: a module named
  "openapi" whose controller injects *gonest.RouteTable, builds the document
  once in OnApplicationBootstrap (routes are complete then) and serves
  opts.JSONPath (default /openapi.json) and opts.UIPath (default /docs) with
  Swagger UI. Its own routes are Hidden.
- Schemas from Go types: json tag names and omitempty (not required), validate
  tags -> required, min/max/len (strings: minLength/maxLength; numbers:
  minimum/maximum; slices: minItems/maxItems), oneof -> enum, email -> format
  email, url/uri -> uri, uuid -> uuid; time.Time -> string date-time,
  time.Duration -> string; pointers -> type [T, "null"] (3.1 style);
  maps -> additionalProperties; named struct types -> $ref
  "#/components/schemas/<PkgName.Type>" sanitised, generic type names
  sanitised; embedded structs flattened; recursion handled via $ref.
  `doc:"..."` -> description, `example:"..."` -> example (converted to the
  field type when possible).
- Parameters from path/query/header tags (path params always required; others
  required if validate has required); request body from json fields (only
  for methods with bodies); form fields -> application/x-www-form-urlencoded.
- Responses: success status from RouteInfo.SuccessStatus() with Out schema
  (NoContent -> no content), plus route Responses docs, plus standard error
  responses (400 when the In type has fields, 401/403 when the route has
  guards, 500 always) referencing an ErrorBody component.
- operationId: ControllerType.Method from Handler.Name, unique. Tags: route
  tags, else controller tags, else the first path segment. Summary,
  description, deprecated, security from config. Gin path ":id" -> "{id}",
  "*any" -> "{any}". Hidden routes skipped.
- Options: Info (title, version, description), Servers, SecuritySchemes
  (helpers BearerJWT(), APIKeyHeader(name)), JSONPath, UIPath, DisableUI.
- Swagger UI: download swagger-ui-dist from npm (`npm pack swagger-ui-dist@5`
  works on this machine: registry.npmjs.org is reachable), embed only
  swagger-ui-bundle.js, swagger-ui.css and the LICENSE into openapi/ui/ with
  embed.FS; serve a small HTML page referencing them by relative URL. No CDN.
- `openapi.WriteFile(doc, path)` writes pretty JSON (for CI/codegen).

## Acceptance
- Golden tests (testdata/*.json, -update flag) on a sample set of routes built
  by hand as []*gonest.RouteInfo (do not depend on gonest.New in unit tests).
- Validate generated documents structurally in tests (all $refs resolve, every
  path param declared, operationIds unique).
- One integration test using gonest.New + httptest hitting /openapi.json and
  /docs (B1 is merged before you finish; if New is still a stub, t.Skip).
- Coverage >= 85%. Handoff: docs/handoff/b2.md.
