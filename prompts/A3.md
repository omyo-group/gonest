# Agent A3: config and logger modules

## You own
modules/config/ and modules/logger/. Both are ordinary Gonest modules built
ONLY from the public root package `github.com/omyo-group/gonest` (no internal
imports): they are the reference for third-party modules. The App itself is
implemented later (B1), so test your modules by calling the provider
constructors and module fields directly; add one integration test file guarded
with `t.Skip` when gonest.New returns core's not-implemented error, so it
starts passing automatically after B1 merges.

## Build: config
- `config.ForRoot[T any](opts config.Options) *gonest.Module`: module named
  "config", Global true by default (opts.NotGlobal to disable), providing *T
  and exporting it. Loading happens in the provider constructor so failures
  surface at bootstrap.
- `config.Load[T any](opts Options) (*T, error)` exported for use outside DI.
- Sources, lowest to highest precedence: `default:"..."` tags, .env files
  (opts.EnvFiles, default [".env"], missing files ignored unless
  opts.RequireEnvFiles), real environment variables (opts.Lookup for tests,
  default os.LookupEnv). Field tag `env:"DB_URL"`; nested structs use the
  `envPrefix:"DB_"` tag; untagged leaf fields derive UPPER_SNAKE names from the
  Go field name with the parent prefix. opts.Prefix applies to all (e.g. "APP_").
- Types: string, bool, ints, uints, floats, time.Duration, time.Time (RFC3339),
  url.URL / *url.URL, []string and []int (comma separated), types implementing
  encoding.TextUnmarshaler.
- Write your own small .env parser (KEY=VALUE, quotes, `export` prefix,
  comments, blank lines); no dependency.
- Validation with validator/v10 `validate` tags after loading; report ALL
  problems in one error naming env variables.
- `secret:"true"` fields: provide `config.Redacted(v any) string` that renders
  the struct with secrets as "******", for logging.
- `config.ForFeature[T any](opts) *gonest.Module` for module-local sections:
  not global, exports *T.
- YAML is out of scope (no dependency allowed); mention it in the handoff.

## Build: logger
- `logger.ForRoot(opts logger.Options) *gonest.Module`: module named "logger",
  global, providing *slog.Logger. Options: Level (slog.Level), Format ("json" |
  "text", default json when GIN_MODE=release else text), Output io.Writer
  (default os.Stdout), AddSource bool, static Attrs.
- `logger.RequestLogger(l *slog.Logger) gin.HandlerFunc`: assigns/propagates a
  request id (X-Request-ID header, generated if missing using crypto/rand,
  echoed in the response), stores a child logger with request_id under the gin
  key `logger.ContextKey` and logs method, path, status, latency, bytes,
  client ip at the end (level by status: 5xx error, 4xx warn, else info).
- `logger.FromCtx(ctx *gonest.Ctx) *slog.Logger` returns that child logger or
  ctx.Logger().

## Acceptance
- Table tests for precedence, env file parsing edge cases, type conversion,
  validation aggregation, redaction, ForFeature isolation, request logger
  output (parse JSON lines), request id propagation.
- Coverage >= 85% per package. Handoff: docs/handoff/a3.md.
