# Agent B3: testing kit

## You own
gonesttest/ only. Use the public root package; you may import
internal/core if strictly necessary (same module), but prefer gonest.

## Build
- `gonesttest.New(t testing.TB, root *gonest.Module) *Builder`.
  Builder methods (chainable): `OverrideProvider(p gonest.Provider)` replaces
  every provider with the same token anywhere in the graph (build a shadow
  copy of the module graph — never mutate the caller's modules, they are often
  package-level vars shared by tests); `OverrideModule(old, new *gonest.Module)`;
  `WithOptions(opts ...gonest.Option)`; `Compile() *App` which calls gonest.New
  with WithoutStartupLog and a discard logger by default, fails the test on
  error, and registers t.Cleanup(app.Shutdown).
- Generic helper: `gonesttest.Get[T](app *App) T` (fails the test on error).
- HTTP: `app.Request(method, path string) *Request` with WithHeader,
  WithQuery, WithJSON(v), WithBody(io.Reader, contentType), WithBearer(token);
  `.Do() *Response` using httptest.NewRecorder against app.Handler();
  Response helpers: `Status() int`, `Body() []byte`, `JSON(v any)`,
  `ExpectStatus(code) *Response` (fails test with body in message),
  `ExpectJSON(v any)` (decode + reflect.DeepEqual against expected),
  `ExpectHeader(k, v)`, `ExpectErrorMessage(substr)` for ErrorBody.
- Unit helpers for pipeline components: `gonesttest.NewCtx(t, opts...)` returns
  a *gonest.Ctx backed by a gin test context (options: method, path, headers,
  route metadata via a RouteInfo), and `gonesttest.Recorder(ctx)` to inspect
  what a filter wrote.

## Acceptance
- Rewrite (in gonesttest) an integration test of a 2-3 module app with
  overrides: a repository replaced by a fake, a guard replaced by an allow-all
  provider registered with AppGuard, etc.
- example_test.go with runnable Examples shown in go doc.
- Coverage >= 85%. Handoff: docs/handoff/b3.md.
